## 📖 Overview

**Amin Hospital** is an enterprise-ready healthcare platform designed to streamline patient interaction, appointment workflows, and medical care accessibility. Built with performance and user accessibility in mind, the platform delivers an intuitive interface backed by a modern web architecture.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🏥 **Interactive Hero & Services** | Dynamic display of clinical departments, specialties, and emergency contacts. |
| 👨‍⚕️ **Doctor Directory** | Searchable directory of medical specialists with qualifications and availability. |
| ⭐ **Patient Reviews** | Real-time review and feedback component (`PatientReviewsSection`) for patient trust. |
| 🔄 **Guided Onboarding** | Interactive modal flow for patient onboarding and preference management. |
| 📱 **Responsive UI** | Mobile-first, fluid layout built with Tailwind CSS for seamless viewing across devices. |
| ⚡ **High Performance** | Fast page loads and instant interactions powered by Vite & React. |

---

## 🏗 Architecture & Tech Stack

### Frontend Framework
- **Core:** React 18+ (Vite)
- **Styling:** Tailwind CSS, PostCSS
- **Icons:** Lucide React
- **Code Quality:** ESLint & Oxlint

### Backend & Storage
- **Runtime Environment:** Node.js (`amin-backend`)
- **API Architecture:** RESTful APIs

## 🚀 Quick Start Guide

### Prerequisites

Ensure you have the following installed locally:
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Git](https://git-scm.com/)

### 1. Installation

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone [https://github.com/Amuriii10/Amir-Hospital.git](https://github.com/Amuriii10/Amir-Hospital.git)

# Navigate into the project folder
cd "Amin Hospital"

# Install Frontend dependencies
npm install
